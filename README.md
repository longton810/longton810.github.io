# Dental Notes homepage

The homepage uses `index.html` with all styling included, plus `tooth-avatar.png` and `long-ton.webp`. Keep these files together and upload all three to GitHub. It links to your existing Odontogram, NPS, Composite, Recall, and Medical consult apps.

Open `index.html` locally to preview it.

To use it as your main GitHub Pages homepage, put `index.html` in the root of a repository named `longton810.github.io`. Enable GitHub Pages for that repository using the branch containing the file and the root folder. The intended homepage address is https://longton810.github.io/.

If that repository already contains a homepage, replacing its `index.html` will replace the existing homepage. You can also upload this file to a separate repository and use that repository's GitHub Pages address.

To change the Firefox tab name, edit the `<title>` near the top of `index.html`.

Medical consult links to https://longton810.github.io/consult/. Publish the MedicalConsultation folder contents in a repository named `consult`, or change the button link to match your repository name.

All tool buttons open in a new browser tab, keeping the homepage open.

All homepage text uses Arial.

Extraction and Referral buttons open `/extraction/` and `/referral/` in new tabs. These destinations assume repositories with those names; change their links if your repository names differ.

RCT and Crown open `/rct/` and `/crown/` in new tabs. These links assume repositories named `rct` and `crown`.

COE opens `/coe/` in a new tab, assuming a repository named `coe`.

Drag cards onto another card to rearrange the menu. The order is saved in this browser; clicking a card still opens its tool in a new tab.

The portrait includes cursor-following eyes drawn as a lightweight overlay. The source portrait stays unchanged. Eyes recenter when the pointer leaves; reduced-motion preferences disable tracking.

Upload `dental-pattern.svg` with the homepage files; it provides the dental icon background.
